# ♻️ ReLoopAI — AI-Powered Waste to Business Opportunities

**Turn waste into business opportunities with AI. Build a more sustainable future, one idea at a time.**

ReLoopAI is an AI-powered web application that transforms waste materials into potential business opportunities. Enter a waste type and quantity to explore three AI-generated ideas, including estimated startup costs, selling prices, expected profits, and practical explanations — all tailored to encourage sustainable entrepreneurship.

## 🌍 Live Demo

**Try ReLoopAI:** https://re-loop-ai.vercel.app

**Backend API Documentation:** https://reloopai.onrender.com/docs

## ✨ Features

- ♻️ **AI-Powered Waste Analysis** — Analyze different waste materials.
- 💡 **Three Business Opportunities** — Discover potential ways to reuse or repurpose waste.
- 💰 **Estimated Startup Costs** — Explore approximate initial investment requirements in INR.
- 📊 **Pricing and Profit Insights** — View estimated selling prices and expected profit per unit.
- 🌱 **Sustainability-Focused Ideas** — Explore reuse, recycling, and circular-economy opportunities.
- ⚡ **Interactive Web Interface** — React frontend connected to a FastAPI backend.
- 🤖 **Google Gemini Integration** — Generate business suggestions using AI.

> **Note:** All costs, prices, and profits are estimates generated by AI, not guaranteed market values or financial advice. Actual results depend on location, material quality, processing costs, and market demand.

## 🚀 Run Locally

### Prerequisites

- Git
- Node.js and npm
- Python 3.10 or a compatible version
- A Google Gemini API key

### 1. Clone the repository

```bash
git clone https://github.com/mdnawedullah09/ReLoopAI.git
cd ReLoopAI
```

### 2. Configure the backend

Open a terminal in the project root:

```powershell
cd backend
python -m venv .venv
```

Activate the virtual environment on Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the Python dependencies:

```bash
pip install -r requirements.txt
```

Create a file named `.env` inside the `backend/` directory and add your own Gemini API key:

```env
GEMINI_API_KEY=your_gemini_api_key_here
```

Start the backend:

```bash
uvicorn main:app --reload
```

The backend will usually run at:

- API: http://127.0.0.1:8000
- API documentation: http://127.0.0.1:8000/docs
- Health check: http://127.0.0.1:8000/api/health

Keep the backend terminal running.

### 3. Start the frontend

Open a **second terminal** in the project root:

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite, usually:

http://localhost:5173

**Important:** The current frontend uses the deployed backend URL. If you want to run the entire application locally, configure the frontend API URL for your local backend and allow your local frontend origin in the backend's CORS settings.

## 🔐 Security

- Store your Gemini API key in `backend/.env` for local development.
- Configure `GEMINI_API_KEY` as an environment variable in your backend hosting service for production.
- Never commit API keys, passwords, or other secrets.
- Keep `.env`, Python virtual environments, and `node_modules` out of Git.
- Restrict production CORS origins to trusted frontend domains.

## ♻️ Waste Materials and Business Opportunities

ReLoopAI helps users explore potential business opportunities by turning waste materials into ideas for reuse, recycling, and sustainable products.

### How It Works

1. Select a waste material in the application.
2. Explore AI-generated business ideas related to that material.
3. Review the estimated startup costs, potential selling prices, and profit estimates.
4. Research the most promising idea before investing in a real business.

### Potential Applications

- **Plastic Waste:** Explore ideas for recycling and repurposing suitable plastic materials.
- **Paper Waste:** Investigate recycled paper products and other reuse opportunities.
- **Organic Waste:** Explore composting and other suitable organic-waste applications.
- **Textile Waste:** Investigate upcycling old clothes and fabric scraps.

*These are examples of possible applications, not guaranteed recommendations generated by the app. Actual feasibility depends on material quality, safety, local regulations, costs, and market demand.*

### Important Note

ReLoopAI provides AI-generated suggestions and approximate financial estimates for educational and exploratory purposes. Users should independently verify costs, selling prices, demand, and profitability before making business decisions.
